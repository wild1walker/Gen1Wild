# Gen1WildUI

The other half of the Gen1Wild suite: everything that makes Red *look*
better, drawn in Red's own font, boxes and borders so it still looks like Red.

Battles happen somewhere now, against real backdrops. The battle menu is four
buttons instead of four words in a row. The Pokédex has a Pokémon beside every
entry, base stats, evolutions, movesets, and a map that tells you where to go
looking. Bill's PC is an actual box you can pick a Pokémon up out of. Your
party wears its own colours instead of six shades of the same salmon. The bag
has pockets, icons and a search. Every item has a picture and a sentence
saying what it does, everywhere items are listed. Even the lift panel got
tidied up.

Eleven features, one install, all of them on out of the box.

## Take as much or as little as you like

Every feature is its own row in `OPTION > GEN1WILD UI`, on or off, with its
own settings behind it. Some land the moment you change them, some want a
relaunch, and the menu tells you which is which rather than pretending.

The features know about each other, so the party menu reads the Pokédex and
the box when they are on, but none of them needs the others to work.

`MENU LAYOUT` and `MOD MANAGER` are also in
[Gen1WildQOL](https://github.com/wild1walker/Gen1WildQOL). Install both
bundles and they sort it out between themselves.

## Before you install

Uninstall the standalone versions of anything above. They install the same
hooks, so the manifest declares them as conflicts. Settings do not carry over.
